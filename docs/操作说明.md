# 操作说明

## 1. 范围

本包只提供主要结果的推理复现，不提供训练入口。推理配置从四个 `best.pt` 的内嵌 `cfg` 读取；模型参数和 128→10 probe 均使用 `strict=True` 加载。

| 运行层级 | 内容 | 依赖 |
| --- | --- | --- |
| 快速核验 | checkpoint、同轮 TensorBoard、时间常数、图、视频和哈希 | CPU；无需 MNIST/SpikingJelly |
| 运行库冒烟测试 | 四个 checkpoint 严格加载并各执行一个保存样本 | CPU 或 GPU；旧版 SpikingJelly |
| 120 样本重放 | 五种条件下的预测、表征和逐层脉冲率 | MNIST；CPU 或 GPU |
| 完整主结果 | 四配置 × 五个 10000 样本测试集 | MNIST；建议 GPU；约 13 GiB 缓存 |

## 2. 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

快速核验可直接运行。需要神经网络推理时再执行：

```bash
bash scripts/setup_full_runtime.sh
```

该脚本检出 SpikingJelly 提交 `73f94ab983d0167623015537f7d4460b064cfca1`，因为 checkpoint 对应代码使用历史接口 `spikingjelly.clock_driven`。

## 3. 快速核验

```bash
bash scripts/run_quick_demo.sh
```

流程会：

1. 从四个 checkpoint 重算同轮五项分数和逐通道时间常数；
2. 与 TensorBoard 中相同轮次的标量核对；
3. 重建证据图和软件演示；
4. 校验 `EVIDENCE_MANIFEST.json` 中的文件大小及 SHA-256。

结束时应出现：

```text
Evidence verification PASS
Quick demo PASS
```

## 4. 检查推理运行库

```bash
export PYTHONPATH="$PWD/src:$PWD/vendor/spikingjelly"
python scripts/check_inference_runtime.py
```

脚本严格加载 `bio`、`equal`、`reverse`、`fixed` 四个 checkpoint，并用保存的标准条件示例执行一次完整 16 帧前向传播。

## 5. 120 样本配对重放

先准备 MNIST：

```bash
python scripts/download_mnist.py
```

然后运行：

```bash
bash scripts/run_full_replay.sh --device cuda:0
```

CPU 可使用较小批量：

```bash
bash scripts/run_full_replay.sh --device cpu --batch-size 8
```

输出位于 `outputs/replay/`。脚本自动调用 `compare_replay.py`：输入、标签、索引和预测必须完全一致；表征容差为 `1/256`，平均脉冲率容差为 `1e-5`，用于容纳 CUDA 卷积次序导致的极少数阈值边界脉冲差异。

## 6. 重新产生主要结果

四配置、五测试条件全部运行：

```bash
export PYTHONPATH="$PWD/src:$PWD/vendor/spikingjelly"
python scripts/evaluate_main_results.py \
  --data-root "$PWD/.data" \
  --device cuda:0
```

只运行递减配置：

```bash
python scripts/evaluate_main_results.py --profiles bio --device cuda:0
```

首次执行会按原始顺序生成五个测试缓存。不要改为逐样本独立随机种子，否则会改变测试刺激。使用 `--rebuild-cache` 可强制从 MNIST 重新生成。结果写入 `outputs/inference/main_results.csv`，每项同时列出重新推理准确率和 checkpoint 保存值。

## 7. 结果口径

1. 表1使用每个配置单一 `best.pt` 内的五项分数，不使用各测试项分别取峰值。
2. `training_peak_metrics.csv` 是旧图口径说明，不是表1数据。
3. 四个 checkpoint 都是随机种子 0；递减配置在五项现有单次比较中占优，但没有多种子显著性检验。
4. 均匀预算为 0.272484，与 0.271875 近似匹配；固定配置预算为 0。
5. 120 样本脉冲率和 PCA 是描述性结果，不单独证明层级功能因果关系。

## 8. 上传前检查

```bash
bash scripts/run_quick_demo.sh
export PYTHONPATH="$PWD/src:$PWD/vendor/spikingjelly"
python scripts/check_inference_runtime.py
git status --short
```
